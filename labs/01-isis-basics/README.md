# Лаба 01 — IS-IS: NET, уровни, соседства, DIS

**Модуль 9, после уроков 1–2.** Цель: увидеть руками то, что было в теории —
как NET определяет зону и system-id, кто с кем дружит на L1 и L2,
кто стал DIS и зачем Hello раздут до MTU.

## Топология

```
        area 49.0001              |        area 49.0002
  [r1  L1] ---------------- [r2  L1/L2] ---------------- [r3  L2]
   lo 203.0.113.1/32         lo 203.0.113.2/32           lo 203.0.113.3/32
   eth1 192.0.2.1/30         eth1 192.0.2.2/30
                             eth2 198.51.100.1/30        eth1 198.51.100.2/30
```

| Роутер | NET | is-type |
|---|---|---|
| r1 | 49.0001.0000.0000.0001.00 | level-1 |
| r2 | 49.0001.0000.0000.0002.00 | level-1-2 |
| r3 | 49.0002.0000.0000.0003.00 | level-2-only |

## 1. Соседства

На **r2**:

```
show isis neighbor
```

Запиши: сколько соседей, на каком уровне каждый, состояние.

## 2. Кто DIS

На **r2**:

```
show isis interface detail
```

Найди, кто DIS на eth1 и на eth2, и на каком уровне.

## 3. Hello с padding — в живом захвате

С хоста (не из vtysh):

```
sudo ip netns exec clab-isis01-r2 tcpdump -nni eth1 -c 4 -vv isis
```

Посмотри на длину кадра Hello и на TLV, которые занимают остаток.

## 4. Таблица маршрутизации L1-роутера

На **r1**:

```
show ip route
```

```
show isis database
```

Обрати внимание: какие префиксы r1 знает поимённо, а каких нет.

Проверка связности (с хоста):

```
sudo docker exec clab-isis01-r1 ping -c 3 -I 203.0.113.1 203.0.113.3
```
