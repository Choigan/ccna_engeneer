# ccna_engeneer

Учебный стенд и тетрадь по пути **сетевой инженер ISP → CCNA → CCNP Service Provider → NetDevOps**.

## Как устроено

| Папка | Что внутри |
|---|---|
| `labs/` | Лабораторные: топология containerlab + конфиги FRR + задания и вопросы |
| `notes/` | Конспекты (`.md` + готовый `.html`) |
| `quizzes/` | Проверочные и диагностические тесты |
| `.devcontainer/` | Окружение для GitHub Codespaces: Docker + containerlab ставятся сами |

## Как запустить лабу без своего железа

1. На странице репозитория: **Code → Codespaces → Create codespace on main**.
2. Дождаться окончания сборки (первый раз — несколько минут, ставится containerlab).
3. Открыть README нужной лабы и идти по шагам.

Бесплатной квоты GitHub хватает примерно на 60 часов в месяц на 2-ядерной машине.
Codespace останавливается сам после простоя; останавливать его вручную после занятия — хорошая привычка.

## Цикл сдачи

1. Выполнил лабу → ответы в `ANSWERS.md` в папке лабы.
2. `git add` → `git commit` → `git push`.
3. Пишу в чат «готово» → получаю разбор.

## Правила репозитория

- Только документационные адреса (RFC 5737: 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24).
- Никаких адресов, имён и конфигов боевой сети.
